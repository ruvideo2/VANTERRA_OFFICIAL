# VANTERRA — официальный сайт проекта

Готовый статический сайт для GitHub Pages. Игра VANTERRA — независимый 3D-проект на Godot Engine в разработке.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub (например, `VANTERRA`).
2. Загрузите **содержимое этой папки** в корень репозитория (не сам ZIP).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
5. После публикации адрес будет примерно `https://USERNAME.github.io/VANTERRA/` (замените USERNAME на свой логин).

Сайт работает без сборки и сервера. Для проверки локально откройте `index.html`.

## Содержимое
- `index.html` — весь сайт, стили и анимации.
- `logo.png` — логотип игры.
- `vanterra-sunset.png` — изображение города.
- `favicon.svg` — иконка вкладки браузера.
- `.nojekyll` — отключение ненужной обработки Jekyll на GitHub Pages.

## Примечание
На сайте нет ссылки на скачивание игры, поскольку файл игры не предоставлен. Также не добавлены вымышленные скриншоты геймплея или дата релиза.
